# Overlay 利用ガイド

Overlay は、元のドキュメントに一切手を入れずに **添削（レビューコメント）を重ねて表示** するためのツールです。
Markdown ファイルや Web ページを読み込み、選択した範囲にコメントや修正提案を付けることができます。

## なぜ必要か

新規に作成されたドキュメントのレビューでは、指摘の範囲が広くなりがちです。
Word のコメント機能のように本文へ直接書き込むと、原本が汚れてしまうので、レビュー用のコピーを作る必要があるため、管理が煩雑になります。

Overlay では指摘を別ファイル（`*.overlay.json`）に保存するので、原本はそのままです。

## 基本的な使い方

1. `overlay serve docs/` でサーバを起動する
2. ブラウザで文書を開き、気になる箇所を選択する
3. 「コメント」または「修正提案」を入力する
4. 他のレビュアーとリアルタイムに共有する

## 文書が更新されたとき

文書が更新されると、指摘箇所の特定にはテキストの引用と前後の文脈を使用することができます。
引用がそのまま見つかれば「一致」または「位置移動」、本文が少し変わっていれば「本文変更あり」、見つからなければ「参照先消失」として一覧の最後にまとめて表示されます。
